# LDpred2-LDSC
Pipeline for estimating heritability and genetic correlations from GWAS summary statistics

## LDpred2 ##
LDpred2 software and tutorial are available at https://github.com/AndreAllegrini/LDpred2, https://choishingwan.github.io/PRS-Tutorial/ldpred/, and on the paper written by Privé et al (DOI: 10.1093/bioinformatics/btaa1029).
HapMap3+ was used as LD reference for calculating effect sizes: https://figshare.com/articles/dataset/LD_reference_for_HapMap3_/21305061

## LDSC ## 
LDSC software is available at https://github.com/GenomicSEM/GenomicSEM and https://rpubs.com/MichelNivard/640145
